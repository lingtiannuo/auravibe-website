# AuraVibe website

Static site for https://auravibenyc.com, served by GitHub Pages.

- Pages: `index.html`, `events.html`, `event-*.html`, `about.html`, `recaps.html`, `partners.html`, `faq.html`, `apply.html`, `conduct.html`, `privacy.html`, `404.html`
- Styles and script: `assets/style.css`, `assets/app.js`
- Form backend: set `CONFIG.endpoint` at the top of `assets/app.js` to the Google Apps Script web-app URL.
- Photos: add image URLs to `PHOTOS` in `assets/app.js` to replace the grey placeholders.
